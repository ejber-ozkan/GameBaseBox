Altirra ROM Image Set (Altirra OS & Altirra BASIC)
==================================================

This directory contains open-source replacement firmware ROMs for Atari 8-bit computers (Atari 400/800/XL/XE):
- ATARIXL.ROM   (AltirraOS for XL/XE/XEGS Computers)
- ATARIOSB.ROM  (AltirraOS for 400/800 Computers)
- ATARIBAS.ROM  (Altirra 8K BASIC)
