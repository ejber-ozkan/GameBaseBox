# UI sound sets

## Original samples (default)

The MP3 files in this folder are retained C64 game samples. Recalled sources
include **Hyper Sports**, **Mikie**, and **Imagine Software games**. These names
are source leads for the collection, not a verified attribution for each file.
The samples are reported to be shorter than ten seconds. Duration and credit
do not establish permission; redistribution permission remains unverified.
No ownership of the sampled game audio is claimed.

## Synthesized retro alternatives

The WAV files in `synthesized/` are independently synthesized tones made for
GBBox using oscillators, pitch sequences and amplitude envelopes. No game
recordings were used to generate them. They follow the same cue names so
Settings → Theme & UI can switch sets without replacing the originals.

The sound-set choice is saved with application settings. The Menu Sound
Effects toggle controls both sets.
