# Previous release notes

Release notes for previous versions are archived here. The current version's
`RELEASE_NOTES_<version>.md` stays in the repository root, where the release
workflow reads it to create the GitHub release description.

When preparing the next version, move the previous version's notes into this
directory, update README links, and create the new version's notes in the root.
Keep archived notes in version control so earlier release information remains
available. Moving these files does not alter published GitHub release descriptions.
